# 06. Bàn giao và kiểm tra

1. Trước khi báo "xong": mở lại file vừa tạo, kiểm tra nội dung, dàn trang (Word, slide), chạy lại code nếu có.
2. Với báo cáo và slide: đối chiếu con số với nguồn (quy tắc 03), kiểm tra không còn câu nào vượt quá bằng chứng.
3. Khi giao việc, nói: file nằm ở đâu, nội dung chính, điều chưa làm hoặc chưa chắc, và việc An cần làm tiếp.
4. Phát hiện lỗi ở tài liệu đã giao thì nói thẳng, sửa, và ghi vào nhật ký.
5. Kết thúc mỗi việc: cập nhật bảng nhật ký ở cuối `docs/KE_HOACH_THUC_HIEN.md`.
6. Sản phẩm cuối kỳ phải đủ: code demo, dataset (nguồn và script tải), bài báo gốc, báo cáo, slide.
7. Giữ danh sách lỗi đã biết (hiện có): PDF 48 sai; hai file 46; hạng 11 bài mới chưa dò; danh sách 20 bài chưa chốt. Xóa khỏi danh sách khi đã sửa.
